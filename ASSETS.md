# Assets

Every visual in Ember Arena comes from Unity itself or is generated by the game's own code. There are no third-party assets and no audio.

| Asset | Used for | Source |
|---|---|---|
| Circle sprite | Player, enemies and bullets | Unity's built-in 2D sprite, made with Hierarchy, 2D Object, Sprites, Circle. It ships in the Unity 2D Sprite package. Each prefab tints it with its own colour. |
| Arena walls | Invisible boundaries | Empty objects with Box Collider 2D components. No art. |
| HUD panels, health bar and cards | Score, health, wave pill, title and game over screens | Built in code by `Assets/Scripts/UI/HudController.cs`. The rounded panel shape is a small texture generated at runtime. |
| Font | All HUD text | Unity's built-in legacy font, loaded as `LegacyRuntime.ttf`. |
| Colours | Everything | Chosen by me: an ember palette of dark brown, orange and cream. |

## Third-party assets

None. No packs were downloaded, so there is nothing to attribute.

## Unity packages

The project uses the packages that come with the Unity 6 Universal 2D template (for example Universal Render Pipeline and 2D Sprite). They are listed in `Packages/manifest.json`.
